# RuleProof – rules for AI coding agents, measured not guessed

RuleProof turns a repository's lived history — review comments, reverts, and CI
failures — into concrete coding rules for AI agents, then A/B-tests each rule
with Bob to keep only the ones that measurably improve outcomes. No guessing,
no hand-waving: every rule earns its place with data.
